# Автосервис «Панорама» — сайт

Статический сайт (HTML/CSS/vanilla JS) для автосервиса «Панорама», Москва, посёлок Знамя Октября, 32А.
Публикуется через GitHub Pages из ветки main.

Источники данных: мини-сайт и карточка организации на Яндекс Картах (контакты, режим работы, прайс, удобства, отзывы, рейтинг, фото).
